# URL_Shortener

URL Shortener

A simple Python project that converts long URLs into short and easy-to-share links.

Inspired by services like Bitly.

Features
Shorten long URLs
Generate random short codes
Retrieve original URLs
Simple terminal-based interface
Technologies Used
Python
Dictionaries
Random module
String module
Project Structure
url-shortener/
│
├── main.py
└── README.md
How It Works

Example:

Original URL:
https://www.youtube.com/watch?v=abc123

Generated short URL:

short.ly/xYz91

When entering the short code:

xYz91

The program returns the original URL.

Installation
Clone the repository
git clone https://github.com/your-username/url-shortener.git
Open the project folder
cd url-shortener
Run the project
python main.py
